The purpose of the application is to store student records in a List<Student> and use LINQ queries to retrieve and display selected information. It can also filter students by program and GPA, search for individual records, and calculate summary information.
•	How student records are created or loaded 
The student records are loaded by starting the program.
•	How to run each query 
To search students by ID or name, type into the search bar and click the search button. To Filter by GPA select the GPA you want to filter and then click the Filter GPA button. To filter by Program, select the program from the drop-down menu and click the Filter Program button.
